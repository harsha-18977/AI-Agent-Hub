## How to Run Locally

### Backend (Flask)
1. Navigate to the backend folder: `cd backend`
2. Start the server: `flask run` (runs on port 5000)

### Frontend (React)
1. Navigate to the frontend folder: `cd frontend`
2. Start the development server: `npm run dev` or `npm start`
